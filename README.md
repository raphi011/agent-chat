# agent-chat

I'd like to create a mobile App (iOS first, android maybe later) that lets me
receive and send messages from an LLM. My main use case is to communicate with
my n8n workflows so that i can talk to the AI Agent node on my phone.

## Features

- Send and Receive messages from n8n Agent workflows.
- Realtime chat (no polling)
- Receive one way push notifications (similar to pushover)
- Multiple Chat Threads
- Rich Markdown Formatting
- Uses Kotlin Native for cross platform UI
- End-to-End Encryption
- Easy integration with n8n
- (Later) Device synchronisation, e.g. ipad <-> iphone
- n8n node to talk to this new app
